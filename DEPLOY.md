# Putting Chito online for a demo (free)

What you end up with:

| Part | Where it runs | Cost |
|---|---|---|
| API server | **Render**, free plan → `https://chito-api-8js0.onrender.com` | ₹0 |
| Database | MongoDB Atlas (already set up) | ₹0 |
| Product photos | ImageKit (already set up) | ₹0 |
| Customer app | **APK** built by Expo (EAS), installed on phones | ₹0 |
| Admin dashboard | Your PC (`npm run dev`), pointed at the Render API | ₹0 |

> **Demo mode:**
> - The online server keeps **OTP 1234**, so anyone with the APK can log in with any number.
> - It also allows **ordering from anywhere at any hour**; the app and admin show "TEST MODE".
> - Razorpay stays on **test keys**, so no real money moves.
> - Share the APK only with people you trust. Before a real launch, follow "Going live" at the end.

---

## Step 1: Let Render reach your database (MongoDB Atlas)
1. Open [cloud.mongodb.com](https://cloud.mongodb.com) → your project → **Network Access**.
2. **Add IP Address** → **Allow access from anywhere** (`0.0.0.0/0`) → Confirm.
   Render's free plan has no fixed address. Your database password still protects the data.

## Step 2: Put the code on GitHub
1. Create a **private** repository on [github.com/new](https://github.com/new), named e.g. `chito`. Don't add a README.
2. In a terminal in `D:\My Projects\CHITO`, run these (git is already set up there, and `.env` files are ignored):
   ```bash
   git add -A
   git commit -m "Chito: app, admin and API"
   git branch -M main
   git remote add origin https://github.com/<your-username>/chito.git
   git push -u origin main
   ```
   GitHub asks you to sign in the first time.

## Step 3: Start the API on Render
1. Sign up at [render.com](https://render.com) with your GitHub account. The free plan needs no card.
2. **New +** → **Blueprint** → pick the `chito` repo. Render reads `render.yaml`.
3. It asks for the secret values. Copy each one from `apps/api/.env`:
   - `MONGODB_URI`
   - `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET`
   - `IMAGEKIT_URL_ENDPOINT`, `IMAGEKIT_PRIVATE_KEY`

   The JWT secrets are generated by Render automatically.
4. **Apply**. The first build takes 3–5 minutes.
5. Check it: open `https://chito-api-8js0.onrender.com/health`. You should see `{"ok":true,"db":true}`.

> **If Render gave the service a different address** (e.g. `chito-api-x1y2.onrender.com`), put that address in `apps/mobile/eas.json` (both `EXPO_PUBLIC_API_URL` lines) and in the admin's `.env.local` (Step 5).

*Optional:* Razorpay Dashboard → Settings → Webhooks → add `https://chito-api-8js0.onrender.com/api/v1/webhooks/razorpay` with the event **payment_link.paid** and your webhook secret. Payments work without this; the webhook is a backup.

## Step 4: Build the APK
1. Sign up at [expo.dev](https://expo.dev).
2. In a terminal:
   ```bash
   cd "D:\My Projects\CHITO\apps\mobile"
   npm install -g eas-cli
   eas login
   eas init
   eas build -p android --profile preview
   ```
   - `eas init` links the app to your Expo account and adds a project ID to `app.json`. Say yes.
   - The build runs on Expo's servers (about 10–20 minutes) and ends with a **download link and QR code** for the `.apk`.
3. On an Android phone: open the link → download → install. Allow "install unknown apps" for the browser when asked.

The APK talks to the Render server, so it works anywhere with internet, not just on your Wi-Fi.

## Step 5: Run the admin against the online API
In `apps/admin/.env.local`, change these two lines:
```
NEXT_PUBLIC_API_URL=https://chito-api-8js0.onrender.com/api/v1
NEXT_PUBLIC_SOCKET_URL=https://chito-api-8js0.onrender.com
```
Then `cd apps/admin && npm run dev` and open http://localhost:3000. You log in with the same admin email and password (they're in the database). New orders from the APK appear here live.

*Optional, to use the admin from your phone:* deploy `apps/admin` on [vercel.com](https://vercel.com) (free), with the same two variables plus `NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT`. Then add the Vercel address to `CORS_ORIGINS` on Render, e.g. `http://localhost:3000,https://chito-admin.vercel.app`.

## Step 6: Before you show it to someone
- **Wake the server a minute early.** Open `https://chito-api-8js0.onrender.com/health` in your browser. The free plan sleeps after 15 minutes with nobody using it, and the first request then takes 30–60 s.
- If the app says "No connection" right after opening, wait a moment and pull to refresh.
- Online payment: choose **Pay now**, then **Netbanking → any bank → Success** on Razorpay's test page. After paying, the app comes back by itself.

## Updating the demo
- **Server change:** `git commit` + `git push`. Render redeploys automatically.
- **App change:** run `eas build -p android --profile preview` again and share the new link. Uninstall the old app first if Android complains.

## Going live (later, not for the demo)
1. **MSG91** Auth Key + DLT OTP template in Render's environment, then set `OTP_DEV_MODE=false`, `DEV_ALLOW_ANY_LOCATION=false`, `DEV_IGNORE_STORE_HOURS=false` and `NODE_ENV=production`.
2. A paid Render plan (no sleeping), or another always-on server.
3. **Razorpay live keys** (after KYC) and a **Google Maps** key for the map.
4. Real product photos and prices. A strong admin password.
5. `eas build -p android --profile production` → an `.aab` for the Play Store.
